?先说结论

        
不填 Key 也能用。初始页那几个问题（科目、底子、每天几小时）已经能排出计划，只是话术比较模板化。填 Key 的意义是让 AI 按你的具体情况重写每周任务。


        
1API Key 是什么

        
一串以 sk- 开头的密码，代表你的账号额度。谁拿到都能花你的钱，别截图发人、别发群里。

        
它只存在这台手机上（App 本地存储），不会上传到任何第三方服务器，只在你点「生成计划」时直接发给 AI 厂商。


        
2去哪拿（三条路，按推荐顺序）

        
A. DeepSeek（最便宜，推荐）

        浏览器打开 platform.deepseek.com → 手机号注册登录 → 左侧菜单「API keys」→ 点「创建 API key」→ 弹出一串 sk-...，当场复制（关掉就看不到了）。

        地址填 https://api.deepseek.com/v1/chat/completions，模型填 deepseek-chat。

        充 10 块钱能用很久，一次生成计划大概几分钱。


        
B. 智谱（有免费模型）

        bigmodel.cn → 注册并实名 → 「API Keys」→ 复制。

        地址 https://open.bigmodel.cn/api/paas/v4/chat/completions，模型 glm-4-flash（这个型号免费）。


        
C. 硅基流动（部分模型免费）

        siliconflow.cn → 注册 → 「API 密钥」→ 复制。

        地址 https://api.siliconflow.cn/v1/chat/completions，模型名去「模型广场」找标着免费的那个，原样抄进来。


        
别买淘宝上的「共享 Key」，容易被限流、被封，还可能被拿去做别的。


        
3填进去

        
上面三个框：接口地址、模型、API Key，粘贴 → 点「保存接口设置」。Key 通常有 30–60 位，前后不能有空格。


        
4怎么让它干活

        
在上面那个大框里写清你的情况，越具体越好，例如：

        考金陵科技学院旅游管理专转本，英语差、专业课一般，每天 7 小时，想留最后一个月去集训

        然后点「让 AI 生成 / 重排计划」。等 10–30 秒，计划会自动铺到「计划」页。

        
它会覆盖现在的周计划，但打卡记录、速记卡、背景都不动。不满意就再点一次，或者换个说法再点。


        
5出错了怎么办

        

          
401Key 错了或过期。重新复制一次，注意别漏字符。

          
402余额不足，去厂商后台充值。

          
404接口地址写错了。看第 2 步里的地址，一个字母都不能差。

          
429请求太频繁，等一两分钟再点。

          
超时网络问题，或地址根本不是 chat/completions 接口。

          
返回不是 JSON模型抽风了，再点一次；连着两次就换个模型。

        


        
6这三件事最容易搞错

        
① 把接口地址和网页地址搞混——要的是 .../v1/chat/completions 这种，不是官网首页。

        ② 模型名写错（大小写、横杠），要跟厂商文档一字不差。

        ③ Key 前后带了空格，肉眼看不出来，粘贴后建议删掉首尾空白。

      

      
用的是各家通用的 chat/completions 接口，DeepSeek、通义、Kimi、OpenAI 兼容地址都能填

      
不填 Key 也完全能用：初始页的「基础水平 / 每天几小时 / 留多久刷真题」三个问题由规则引擎直接算计划，离线、免费、不联网。
想用真正的大模型，智谱 GLM-4-Flash、硅基流动的部分模型目前是免费额度，注册后拿 Key 填上面就行。
